# Research in Software Analysis: SmartBFT

## Setup

This project is conducted through WSL and Visual Studio Code.

### Requirements

#### Java
Ensure that Java is installed. If it is not installed follow the following instructions:

`sudo apt update`

`sudo apt install openjdk-17-jdk`

Then check the version using:

`java -version`

#### TLA+ Extension

In order to run .tla files we will need to install an extension in the Visual Studio Codes Extension page through which the following extension should be installed:

`TLA + (Temporal Logic of Actions)`

### Running 

In order to run this, open the Command Palette (Ctrl + Shift + P or Cmd + Shift + P) and click on the following:

`TLA+: Check and debug with TLC`

Enter the additional information prompted.
